# 대시보드 폭·정렬 보완

## 원인과 변경

- 담당 DAG에는 최대 폭 1680px가 적용되지만 Studio는 폭 제한과 가운데 정렬을 해제했다.
  두 페이지의 제목·필터·본문에 동일한 폭 및 반응형 좌우 여백 규칙을 적용했다.
- Studio의 일반 폼 스타일이 공통 필터에 섞였고, 담당 범위 설정은 탭마다 버튼/링크 모양이 달랐다.
  공통 컨트롤의 높이·테두리·글꼴·줄 높이·정렬과 링크 버튼 모양을 명시했다.
- 담당 DAG의 두 열 비율과 카드 높이가 달랐다. 동일 열 너비와 행 높이를 사용하고,
  카드 간격을 16px로 통일했다. Studio GridStack의 간격도 16px로 맞췄다.
- 카드 제목 높이와 상태 배지·버튼·하단 정보의 세로 정렬을 정리했다.
  글꼴에 좌우되던 검색 초기화·패널 조회·복제·삭제·이동 표시는 SVG로 교체했다.

## 확인

- 로컬 Airflow의 1280×720 브라우저에서 두 탭의 공통 영역 위치와 크기, 카드 좌우 경계,
  제목과 아이콘 정렬을 화면 캡처로 비교했다.
- 차트의 전체 실행 데이터 확인 아이콘으로 대화상자가 열리고 42건이 표시되었다.
- 편집 모드의 제목·조회·복제·삭제·이동 아이콘 정렬을 확인하고 편집 종료했다.
  패널 이동·복제·삭제·저장을 실행하지 않았으며 개인 보드는 v9를 유지했다.
- 변경한 workspace.js, studio.js의 Node 구문 검사와 Prettier 포맷을 통과했다.
  집계 쿼리와 권한 API는 변경하지 않았다.
