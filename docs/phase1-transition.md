# Phase 1 전환 계획

2026-09-23 저장소 분리 기준선 이후 진행할 작업입니다. 아래 사항은 구현 완료를 뜻하지 않습니다.

목표 경로: KOBIS/KMDb·서비스 리뷰 → S3 원본/manifest → Python 적재 → 분석용 PostgreSQL STG → dbt DW/Mart.
Snowflake/Databricks 현재 구현은 후속 플랫폼 비교 PoC의 참고 자산으로 보존합니다.

1. 기존 원본 한 묶음을 PostgreSQL에 적재하는 경로를 추가합니다.
2. Snowflake 전용 JSON·날짜·집계 SQL을 PostgreSQL로 이식합니다.
3. 영화/날짜 차원, 일별 흥행 팩트, 출처를 보존하는 리뷰 팩트를 구성합니다.
4. 영화별 흥행, 리뷰 요약, 흥행·평점 통합 마트를 검증합니다.
5. 동일 입력 재실행, 특정 날짜 backfill, 품질 실패 시 게시 차단과 복구를 검증합니다.
6. 검증된 플랫폼 경로로 서비스 게시를 전환합니다.

현재 박스오피스 수집은 상위 목록입니다. 관측 합계를 전체 시장 합계로 표현하지 않습니다.
미관측 날짜와 0을 구분하고 누적 관객수를 날짜별로 합산하지 않습니다.
리뷰 작성일과 가져온 시각의 의미를 확인한 뒤 시계열 지표를 정의합니다.
API 원본의 정책 조건과 서비스 공개 조건을 별도로 유지합니다.

완료 기준: 세 마트가 실제 질문에 답하고, 같은 원본으로 재현 가능하며, 실패 후 복구할 수 있습니다.
새 Agent·학습·감성 분석·Workbench 기능 확장은 이 단계의 완료 조건에 포함하지 않습니다.
