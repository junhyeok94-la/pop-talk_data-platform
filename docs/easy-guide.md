# 데이터 플랫폼 간단 안내

이 프로젝트는 영화·흥행·리뷰 자료를 모아 분석 가능한 표로 만드는 곳입니다.

1. Airflow가 수집 작업을 실행합니다.
2. 원본 API 응답과 수집 완료 기록을 S3에 보존합니다.
3. Python이 원본을 검증하고 정제합니다.
4. 앞으로 PostgreSQL에 적재하고 dbt로 영화·흥행·리뷰 분석 표를 만듭니다.
5. 품질 검사를 통과한 결과만 서비스에 게시합니다.

현재는 1~3의 코드가 있으며 4~5를 연결하는 Phase 1 작업이 남아 있습니다.
실행 방법은 [README](../README.md), 다음 할 일은 [Phase 1 계획](phase1-transition.md)을 참고하세요.
