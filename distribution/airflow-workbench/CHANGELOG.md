# 변경 기록

## 0.1.2-dev

- 기존 설치 점검 옵션 `verify_installation.py --existing` 추가. 프로젝트·DAG 활성 상태를 보존하며 등록한 연결의 DAG·Pool 설정도 검사한다.
- Python 표준 라이브러리만으로 내보낸 파일의 SHA-256을 검증하는 `verify_source.py` 제공.
- 개발 저장소의 export 명령에 `--archive` 추가. 소스 폴더·ZIP·체크섬을 함께 생성하며 버전명의 점을 보존하고 동일 소스로 같은 ZIP을 재생성한다.
- 배포 템플릿을 명시한 파일 목록으로 내보내 임시 접속 정보나 DB 파일의 혼입을 방지한다.
- 설치·평가·비교·검토·적용 구성과 별도 파인튜닝 경로를 수동 실행 가이드로 정리한다.

## 0.1.1-dev

- 추론 연결 ID·Connection ID·DAG·파일명·접속 정보 출처를 함께 표시한다.
- 환경변수 Connection을 포함한 선택 목록과 생성할 DAG 미리보기를 제공한다.
- 대시보드와 Model Lab의 DAG 활성화·일시중지 권한 처리를 통일한다. 실제 평가·학습 제출 시 설정 검사는 유지한다.

## 0.1.0-dev

- Airflow 3.3.1 기반 공통 이미지와 별도 제어·GPU 학습 워커 빌드 구성을 제공한다.
- DB migration, 최초 관리자·보조 역할, 평가·학습 DAG 생성 및 독립 설치 구성을 포함한다.

모든 버전은 로컬 검증용 공개 전 후보이다. 외부 저장소·레지스트리와 작성 코드의 공개 라이선스는 아직 정하지 않았다.
