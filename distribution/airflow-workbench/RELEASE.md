# 공개 배포 준비

이 패키지는 독립 실행을 위한 소스 배포 후보입니다. 외부 저장소·이미지 레지스트리에 아직 공개하지 않았습니다.

1. 프로젝트 이름과 작성 코드의 라이선스를 결정하고 `LICENSE` 및 필요한 `NOTICE`를 추가합니다. Apache-2.0 등을 후보로 검토할 수 있지만 이 문서는 라이선스를 부여하지 않습니다.
2. 작성 코드의 공개 권한과 포함한 의존성의 재배포 조건을 확인합니다. Apache Airflow 기반임을 표시하되 Apache 공식 배포판이라는 인상을 주는 이름·표현은 피합니다.
3. 정적 UI 번들의 `*.LEGAL.txt`, `THIRD-PARTY-NOTICES.txt`를 보존합니다. 사용한 dependency lockfile과 build script도 포함합니다.
4. 검증한 소스 manifest와 이미지 digest, Airflow/Python 버전, 설치 검사 결과를 릴리스에 기록합니다. 워커는 공통 이미지와 따로 버전을 고정합니다.
5. 공개 저장소에는 내보낸 소스만 반영합니다. 설치 후 생성한 `.env`, 데이터, 모델, 로그, DB dump, 사용자 실험 기록을 함께 올리지 않습니다.

공개 시 기본 단위는 공통 소스 저장소 + 공통 Airflow 이미지 + 선택 설치 워커 이미지입니다. 개발 중인 업무 DAG는 소비자가 자신의 DAG 저장소/볼륨으로 추가합니다. 플러그인 설치용 DB migration과 일반 업무 DB migration의 생명주기를 분리합니다.

공통 이미지는 원본 Airflow의 기능과 포함 provider를 유지합니다. 프로젝트 전용 데이터 플랫폼 런타임는 추가하지 않습니다. `training` 이미지는 별도 PyTorch/CUDA 의존성 검증이 필요하며 모델 가중치는 재배포하지 않습니다.
